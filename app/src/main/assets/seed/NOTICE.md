# Exercise catalogue attribution

`exercises-dataset-v1.json` was mechanically derived on 2026-09-09 from the
metadata and instruction text in `hasaneyldrm/exercises-dataset`.

- Repository: https://github.com/hasaneyldrm/exercises-dataset
- Pinned source revision: `7455efae41b330c265e7cd4b78dfa848e7ce5ebd`.
- Licence for code, dataset structure and instruction text: MIT.
- Source media owner: Gym Visual (https://gymvisual.com/).

GymQuest intentionally excludes every Gym Visual `image`, `gif_url`, `media_id`
and media-attribution field from this asset. No Gym Visual image, thumbnail or
animation is included, displayed or downloaded by the app.

For 1,094 unambiguous exact-name matches, the asset also contains a GIF URL from
`mohamedatef90/exercise-library`. The GIF files are packaged in the APK under
`assets/exercise_gifs`; the stored URL is an app-internal asset path. The linked
repository states that it is MIT-licensed, although its published root currently
does not contain a `LICENSE` file. Attribution is retained here and the bundled
media should be removed if its licensing status changes.

Fifteen otherwise exact matches are intentionally omitted because their Spanish
catalogue name and muscle group merge multiple distinct source exercises; this
prevents assigning an incorrect animation.

The GIF URLs are pinned to source revision
`a63d9e0c26a1c233439531f33f035139f5c41464`.
