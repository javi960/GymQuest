# Configuración de minijuegos marciales

El contenido es local y pertenece al usuario. No se descarga ni se comparte.

1. Crea una categoría. Usa `Golpes`, `Partes del cuerpo` o el nombre que resulte útil para tu disciplina.
2. Crea una pregunta, escribe su explicación y selecciona dificultad: fácil, media o difícil.
3. Añade entre dos y seis respuestas. Marca exactamente una como correcta.
4. Guarda y prueba la pregunta. Al responder, GymQuest muestra si fue correcta y la explicación guardada; nunca infiere una respuesta por el texto.
5. Para retirar una pregunta sin perder trazabilidad, archívala. Las preguntas archivadas no se sirven a un minijuego nuevo.

Buenas prácticas: redacta preguntas sin asumir vocabulario de una disciplina, mantén las explicaciones breves y revisa las preguntas después de cambiar una técnica o terminología. Las preguntas de golpes y partes del cuerpo son plantillas de contenido, no consejo médico ni de seguridad.
